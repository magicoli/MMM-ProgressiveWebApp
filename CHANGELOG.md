# Changelog

## 1.0.0

- installable app: name, colors, orientation and icons set in the module config
- fullscreen display, retried on the first tap when the browser refuses it at start
- screen kept awake, requested again when the page comes back
- service worker covering the whole page, smoothing over brief network drops
- Safari home screen title and icon, taken from the manifest
- works with MagicMirror²'s `basePath`
- MagicMirror² logo as default icon
